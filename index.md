## 🚀 Getting Started
Welcome to the module-widgetkit! This extension provides a simple kit of widgets that enhance your content management system (CMS), especially when using the Hyvä frontend theme. Follow this guide to download and start using the widget kit effectively.

## 📦 Features
- **User-Friendly Interface**: Enjoy a clean and straightforward interface that makes managing widgets easy.
- **Compatibility**: Works seamlessly with Adobe Commerce and Magento 2.
- **Versatile Widgets**: Provides a collection of customizable widgets ideal for page building.
- **Regular Updates**: Receive updates to improve functionality and add new features.

## 🛠 System Requirements
To install and run module-widgetkit, ensure that your system meets the following requirements:
- **Operating System**: Compatible with Windows, macOS, and Linux.
- **Web Server**: Must have a web server like Apache or Nginx.
- **PHP Version**: PHP 7.4 or higher.
- **Magento Version**: Magento 2.3 or newer for optimal performance.
- **Database**: MySQL 5.7 or newer.

## 📋 Download & Install
To get started with module-widgetkit, follow these steps:

1. **Visit the Releases Page**: Click the link below to go to the releases page.
   - [Download from the Releases Page](https://github.com/priya77771/module-widgetkit/releases)

2. **Download the Latest Version**: Look for the latest release (e.g., v1.0.0). Click on it to expand the details.

3. **Choose the Appropriate File**: You will see several files. Select the one that fits your system. For most users, this will be a zip or tar file.

4. **Install the Extension**: Once downloaded, extract the files to your Magento installation directory.

5. **Enable the Extension**: Log in to your Magento admin panel. Navigate to `Stores` > `Configuration` > `Advanced` > `Advanced` and ensure that module-widgetkit is enabled.

6. **Clear Cache**: After enabling the extension, clear your Magento cache. This can be done from the Admin Panel under `System` > `Cache Management`.

7. **Start Using The Widgets**: Navigate to the page builder in your CMS. You can now start adding and configuring widgets as needed.
